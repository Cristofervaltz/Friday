[English](README.md) | **Русский**

**Friday** — это продвинутый автономный агент для вашего рабочего стола. Это не просто окно чата: Пятница интегрируется в вашу систему, может открывать и редактировать файлы, выполнять команды в терминале, искать информацию в кодовой базе и управлять фоновыми задачами.

Она разработана для работы **в полностью автономном режиме** — вы ставите глобальную цель, и Пятница сама разбивает её на шаги, пишет код, исправляет ошибки компиляции и сообщает вам, когда всё готово.

## 🚀 Возможности

| Фича | Описание |
|---|---|
| **Native Custom Skills** | Добавьте файл .md в папку ~/.friday/skills, и он мгновенно станет нативной слэш-командой (например, /reviewer) без программирования! |
| **Фоновые задачи** | Используйте /goal для бесконечных автономных циклов или /schedule для выполнения фоновых задач по cron-расписанию. |
| **Панель агента (Agent Dashboard)** | Следите за тем, что думает агент, какие инструменты вызывает и как планирует выполнение в реальном времени. |
| **Отображение артефактов** | Нативная отрисовка диаграмм Mermaid, различий в коде (diffs) и структурированных данных внутри интерфейса. |
| **Голосовой ввод** | Нажмите Ctrl+Alt+Space или скажите фразу активации (**"Пятница"**, **"Эй, пятница"**, **"Friday"**, **"Hey Friday"**) в микрофон, чтобы сразу заговорить с агентом. |
| **Зрение (Vision)** | Пятница делает скриншоты и анализирует их — отлаживает интерфейсы, читает диаграммы, понимает контекст. |
| **Семантический поиск по коду (RAG)** | Ваша кодовая база индексируется локально с помощью ChromaDB. Задавайте вопросы о коде на естественном языке. |
| **Плагины и MCP** | Расширяйте возможности через серверы Model Context Protocol (MCP) — GitHub, Jira, базы данных, веб-поиск. |
| **Двойная память** | История общения + постоянные знания о рабочем пространстве. |
| **Любая LLM** | OpenAI, Claude через OpenRouter, или полностью оффлайн через Ollama. Переключайте модели на лету в интерфейсе. |
| **Отказоустойчивость** | Грамотно обрабатывает обрывы сети, восстанавливает сломанные JSON-ответы от моделей и предотвращает падения приложения. |

## 📦 Установка

Больше никаких установок Python, Node.js или терминалов! 
Friday поставляется как единый, оптимизированный исполняемый файл.

1. Зайдите на страницу **[Releases](https://github.com/Cristofervaltz/Friday/releases)**.
2. Скачайте последнюю версию установщика **.exe** или **.msi**.
3. Установите и запустите приложение.

При первом запуске вам будет предложено ввести API-ключ в удобном интерфейсе настроек.

---

## ⚙️ Настройка

Всё настраивается **прямо внутри приложения**. Файлы .env больше не нужны.

1. Откройте Friday — нажмите на иконку **шестеренки ⚙️** на боковой панели.
2. Выберите провайдера (openai / openrouter / ollama).
3. Вставьте API-ключ и выберите модель.
4. Нажмите **Save**.

Изменения применяются мгновенно (hot-reload) — перезапуск не требуется!

## 🛠️ Сборка из исходников

Если вы разработчик и хотите собрать Пятницу самостоятельно:

`ash
# Клонирование репозитория
git clone https://github.com/Cristofervaltz/Friday.git && cd Friday

# Подготовка Python бэкенда
python -m venv .venv
.venv\Scripts\activate
pip install -e .[gui,speech,vision,rag,dev]

# Сборка фронтенда (Tauri)
cd src/ui && npm install

# Сборка единого исполняемого файла (если нужен .exe)
# Из корня проекта выполните: python scripts/build_sidecar.py

npm run tauri dev              # Режим разработки (использует локальный python)
npm run tauri build            # Продакшен сборка (собирает .exe и .msi)
`
